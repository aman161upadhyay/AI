# Agent Skills format and authoring

Use the specification for format constraints and the authoring guide for local quality checks. These are different contracts: a valid file can still be a poor skill.

- specification.md: canonical format documentation by Agent Skills maintainers and contributors. Its extension changed from .mdx; content is unchanged.
- authoring-guide.md: original synthesis of routing, disclosure, scripts and evaluation practices.
- LICENSE: upstream CC-BY-4.0 documentation licence.
- code-license.txt: separate Apache-2.0 licence for upstream code. No validator code is included.
- SOURCE.md: full source commit, attribution and import scope.
- FOR-AMAN.md: how to author and evaluate a local skill.

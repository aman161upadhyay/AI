# Canonical skills library

A skill is a directory with SKILL.md metadata and on-demand instructions. It may include reviewed scripts and references. A skill teaches a procedure; a tool executes an operation. This is the complete curated set for this repository, not the complete upstream catalogues.

- spec/: canonical format, actual licences and original authoring guidance.
- anthropic/: individually Apache-licensed Anthropic examples, with restricted procedures linked separately.
- community/: pinned source selections and their original licences.
- curated-index.md: every selected skill and reference component, suggested agents, quality limits and overlap.
- excluded.md: licence, duplication and quality decisions.
- security-review.md: located executable behaviors and permission controls.
- FOR-AMAN.md: choosing, evaluating and updating skills.

## Install a selected skill

Copy the chosen directory that contains SKILL.md, including its references, scripts and notices. Do not copy the catalogue root as a single skill. Do not install hooks or run scripts merely because a skill mentions them.

| Harness | Project target and invocation | Caveat |
|---|---|---|
| Claude Code | Copy to `.claude/skills/<skill-name>/SKILL.md`; upstream plugin wrappers use `.claude-plugin/plugin.json` | Validate the installed host's official skills docs. Plugin hooks and extra frontmatter are extensions. |
| Codex | `.agents/skills/<skill-name>/`; invoke `$skill-name` where supported | `agents/openai.yaml` is optional host metadata. See https://developers.openai.com/codex/skills/create-skill. |
| Cursor | `.agents/skills/<skill-name>/` in the inspected installer mapping | Cursor rules remain a separate mechanism in `.cursor/rules/*.mdc`. Restore copied rule references to `.mdc` if explicitly selected. |
| Gemini CLI | `.agents/skills/<skill-name>/` in the inspected installer mapping | Check installed product/version. Conductor's current plugin layout differs from historical Gemini extension guides. |
| Replit | `.agents/skills/<skill-name>/` in the inspected installer mapping | Host-owned workflows and current permission rules override upstream server-start examples. |

Mappings are documentation snapshots, not runtime compatibility tests. Read community/vercel-labs__skills/docs/agents.md and current host documentation before installing. Use host permissions and scoped connections for enforcement; allowed-tools frontmatter alone is insufficient. Automatic arbitrary repository installation is not approved.

## Known gaps

Imported skills have not been run in these harnesses. Some upstream templates have nonportable assumptions. Binary/font exclusions can prevent upstream design examples from running unchanged. Vercel agent-skills declares MIT in README but supplies no complete root licence text in this snapshot; the declaration is retained without inventing a grant. The specification documentation is CC-BY-4.0, not Apache-2.0. Anthropic doc-coauthoring has no individual grant and is link-only.

Microsoft's FastAPI and Pydantic `assets/template.py` files contain unrendered template syntax. They are source templates, not directly executable Python. Fill them through the upstream procedure before parsing or running the generated code.

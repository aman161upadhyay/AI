# Review a run

Ask for all selected cases and every trial, not the best examples. Supply the frozen baseline ID and preapproved release tolerances.

Grant read access to sanitized reports and scoped private evidence only to the verifier. Refuse exporting raw traces to a hosted service without approval. Check one pass and one failure against actual artifacts; verify the grader failed the seeded-defect control.

If required cases errored or remain unknown, keep the release decision incomplete. Compare costs using actual usage, not estimated model reputation. Decide disputed labels with your domain expert, then record the adjudication without deleting the original judgment.

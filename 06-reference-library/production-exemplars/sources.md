# Catalogue provenance

Observation date: 2026-10-25. These are independent annotations, not vendored source or full article conversions. No code, fonts, product screenshots, books, or paid starter content was copied.

GitHub repository HTML supplied rounded stars and root paths. Default-branch Atom feeds supplied the latest observed activity, including dependency/maintenance commits. Raw README/license/manifests and selected schemas supplied implementation evidence. This does not establish contributor diversity, issue-resolution quality, or complete authorization for every repository.

Repository records below use the organization's own source for implementation claims. Tier 2 marks adopted product code; Tier 1 marks first-party platform docs or reference examples. Entries that failed the six-month activity gate are recorded in [superseded.md](superseded.md), not the active tables.

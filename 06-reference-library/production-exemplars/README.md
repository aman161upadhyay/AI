# Production exemplars

Study implemented subsystems rather than copy an entire product stack. These catalogues use first-party repository evidence and docs observed on 2026-10-25.

- [web-apps.md](web-apps.md): 18 application references with stack, data, auth, deployment, and license caveats.
- [mobile-apps.md](mobile-apps.md): shipped clients and first-party examples with reading paths.
- [ui-component-libraries.md](ui-component-libraries.md): active foundations, starters, and dated exclusions.
- [system-design-references.md](system-design-references.md): conceptual sources and maintenance status.
- [deployment-references.md](deployment-references.md): release, database, runtime, and recovery references.
- [FOR-AMAN.md](FOR-AMAN.md): reading order, independent patterns, and eval design.
- [sources.md](sources.md): provenance, activity method, and evidence limits.

## Known gaps

No application was run or deployed for this catalogue. Schema/manifests do not establish complete tenant enforcement. Public-data contamination in evals cannot be excluded. Medusa's current database implementation path and some Appsmith/NocoDB internals remain unverified. Paid starter source was not audited.

# Web application catalogue

Choose references by subsystem. Approximate stars and maintenance observations are as of 2026-10-25, from fetched GitHub pages and default-branch activity feeds. They are adoption signals, not security or efficacy scores.

All entries clear the study bar through substantial adoption and observed recent activity. First-party source/manifests establish stacks below. “Not audited” means enforcement was not traced end to end. An entity's tenant key or an ORM dependency does not prove isolation.

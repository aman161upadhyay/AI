# Aman, how to use the figures

Use the text transcription first. Every figure here that carries data is transcribed next to its paper, and an agent reads the transcription more reliably than it reads a JPEG. Load the image only when you want to check the transcription or show a person the original typography.

Framing to give an agent with vision when you add a figure: "Transcribe this table into Markdown, cell by cell. Mark any cell you cannot read with [unclear]. Do not infer values." Then check the transcription against the image yourself before committing it; that is the step where numbers go wrong.

Access: read-only. Nothing in this folder needs credentials or network access. Attribution and licence for each image are in `SOURCE.md`; keep them when you copy an image elsewhere, and do not add an image whose licence you have not recorded there.

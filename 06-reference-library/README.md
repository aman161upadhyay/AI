# Reference library

Load one relevant reference for a decision. Keep provenance and reuse rights attached to every imported item.

| Folder | Use |
|---|---|
| [papers/](papers/) | Paper references and research material; inspect each item's authors, version, methods, and limitations. |
| [articles/](articles/README.md) | Converted-articles folder; use each conversion's original attribution and source URL. |
| [figures/](figures/) | Figures and visual reference material; check rights before reuse. |
| [production-exemplars/](production-exemplars/README.md) | Production application and component study maps, deployment references, and exemplar-to-eval procedure. |
| [FOR-AMAN.md](FOR-AMAN.md) | How you supply a reference packet and review derived claims. |

Do not treat a research capture as a redistribution license. The catalogues are annotations, not certificates that every referenced system is secure or current.

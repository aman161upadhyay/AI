# Named patterns

Definitions synthesize the sources in sources.md. “Shared decision ledger” and “evidence-gated promotion” are local names, not claims of standardized vendor terminology.

## Progressive disclosure

Expose resource names and descriptions first, then load the selected skill body and supporting references. Anthropic and Hermes use this pattern to keep specialized knowledge out of every startup prompt. Evaluate discovery failures as well as startup size.

## Just-in-time context

Keep lightweight pointers and retrieve exact evidence at the moment it affects a decision. Anthropic describes paths, symbols and search as context-selection tools. Preserve source access so a later session can recheck a compressed claim.

## Filesystem as memory

Persist evidence and state outside the prompt in indexed files. Manus uses this to extend practical working storage. Files require provenance and access controls; their existence does not establish that the agent loaded them.

## Todo recitation

Maintain and reread a short active goal and checklist during long tool sequences. Manus describes this as a way to keep the objective recent. Update completed and invalidated items or the checklist can reinforce a stale plan.

## Keep failures in context

Retain a meaningful error, hypothesis, attempted remedy and observed result. Manus argues against erasing failure history. Compress repetitive output while retaining the causal evidence and its original artifact.

## Compaction

Replace oversized conversation history with a smaller operational summary. Anthropic supports this for long runs. Preserve permission state and original evidence so compression does not turn uncertainty into an invented fact.

## Subagent context isolation

Give a worker a bounded question and isolated scratchpad, then return a compact evidence-backed result. Anthropic uses this for verbose independent exploration. Share constraints and source artifacts to avoid the fragmented truth that Cognition warns about.

## Stable-prefix caching

Keep reusable policy, schemas and serialization deterministic before dynamic observations. Manus and OpenAI describe cache reuse benefits. Stability is a cost mechanism, not evidence that the context is relevant.

## Shared decision ledger

Maintain accepted interfaces, constraints and integration decisions in a common artifact. This synthesis combines Cognition's shared-context caution with Anthropic's worker contracts. Let workers keep private exploration while the lead serializes coupled decisions.

## Initializer plus incremental executor

Prepare the environment and durable progress artifacts once, then execute bounded recoverable increments in later sessions. Anthropic's long-running harness uses this division. Reuse the repository's existing setup procedure rather than adding duplicate startup scripts.

## Procedural learning

Convert a successful workflow and its limits into a versioned skill. Hermes provides editable skill artifacts and approval mechanisms. This is instruction maintenance, not model-weight learning or a guarantee of recursive improvement.

## Evidence-gated promotion

Stage proposed prompt, skill or memory changes, run regression evaluation and obtain authorized review before activation. This local pattern combines Hermes approval gates with held-out tool evaluation. Preserve the prior version for rollback and prohibit the generator from weakening its own verifier.

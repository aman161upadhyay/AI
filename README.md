# AI: a compendium of harnesses for building with AI agents

Owner: Aman Upadhyay. Status: first full release is being assembled (research, curation, and adversarial review in progress on 2026-10-25). This commit initialises the repository with the reference library so the build can continue with normal Git commits.

What will be here:

- 00-foundations: context engineering, prompt engineering, agent architectures, token optimisation, a learning path
- 01-skills-library: vendored and curated agent skills with licences and provenance
- 02-prompts: prompt collections by use case (video, animation, landing pages, CRM and dashboards, UI, marketing, research, code)
- 03-agents: definitions for the research, writing, coding, design, security, adversarial-council, system-design, marketing, and technology-scout agents; each folder has a README.md (what is inside) and a FOR-AMAN.md (what prompt to give, what access to grant)
- 04-harness-components: security guardrails, memory and context, tool design, evals framework, observability
- 05-evals: eval sets and recorded self-test results
- 06-reference-library: papers and articles converted to Markdown, production-quality exemplars
- 07-council: the adversarial review protocol and the logs of every review round applied to this repository

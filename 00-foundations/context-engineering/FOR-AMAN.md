# Control what your agent reads

Ask: “Inspect this failed run. Identify wrong, missing, and irrelevant context separately. Propose the smallest assembly change and an eval that could reject it.”

Supply your task contract, sanitized trace, skill index, source files, and accepted decisions. Grant read-only file search plus access to the relevant raw evidence. Refuse secrets, automatic memory promotion, and arbitrary skill installation.

Read the agent's evidence map before approving its plan. Correct a false research claim before the agent generates code from it. HumanLayer's research-plan-implement account supports this review placement, but does not establish a universal productivity gain.

Run a distractor case, a missing-source case, and a clean-session resume case. Check that your agent preserves permissions and previous failures after compaction. Compare token use and task success against your unchanged baseline. Approve one change at a time.

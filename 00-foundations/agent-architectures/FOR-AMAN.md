# Choose a harness by the missing capability

Ask: “Map my task to the smallest architecture that can pass these checks. Identify the controller, context assembler, dispatcher, and verifier. Explain any worker or memory service that you add.”

Supply your actual tools, permitted actions, representative failures, cost/latency ceilings, existing code, and acceptance cases. Grant read-only source and sanitized trace access. Refuse deployment, IAM changes, and unattended third-party skill installation.

Study Codex for an inspectable coding loop. Study Hermes for skill and memory artifacts. Study OpenClaw for channel/device boundaries. Study Claude Code guidance for human verification workflows. Do not select by star count.

Approve a component contract before implementation. Run cancellation, repeated-tool-failure, unauthorized-side-effect, fresh-session-resume, and cross-tenant cases. Compare one agent against workers at the same total budget. Keep only changes with evidence and a rollback path.

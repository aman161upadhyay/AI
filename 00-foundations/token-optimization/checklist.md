# Run checklist

- [ ] Define acceptance before selecting a cost strategy.
- [ ] Set total token, dollar, wall-time and worker limits.
- [ ] Reserve budget for verification and reporting.
- [ ] Keep stable policy and schemas ahead of changing task state.
- [ ] Confirm model-specific cache fields, prices and actual usage.
- [ ] Search first and bound file/tool results.
- [ ] Retain full evidence externally with redaction.
- [ ] Load only relevant skills.
- [ ] Preserve criteria, failures and approvals before compaction.
- [ ] Account for child usage and duplicate work.
- [ ] Route only evaluated task classes.
- [ ] Batch only independent offline work.
- [ ] Stop repeated failures without new evidence.
- [ ] Include all attempts in accepted-task cost.
- [ ] Reject savings that weaken acceptance or expose data.

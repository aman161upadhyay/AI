# Learn through one evaluated agent product

Build a tenant-aware research assistant over an authorized corpus. Use one project to connect infrastructure, retrieval, protocols, and model training.

- [12-week-plan.md](12-week-plan.md): weekly artifacts and exit criteria for 8 to 12 hours per week.
- [resources-agentic-infrastructure.md](resources-agentic-infrastructure.md): loops, tools, durable execution, and deployment.
- [resources-rag.md](resources-rag.md): retrieval baselines and boundary-level evaluation.
- [resources-training-agents.md](resources-training-agents.md): prompt optimization, SFT, verifiable RL, and scaling.
- [resources-mcp-and-protocols.md](resources-mcp-and-protocols.md): MCP specification and optional A2A.
- [resources-evals.md](resources-evals.md): human labels, deterministic checks, and calibrated judges.
- [FOR-AMAN.md](FOR-AMAN.md): project inputs, permission stages, and weekly review.

P1 means core, P2 targeted supplement, P3 optional. Rankings are editorial decisions for this project. All statuses are as of 2026-10-25. Current means observed active repo or living first-party docs, not API compatibility certification. Foundational means older conceptual work. Search-only means substantive full text was unavailable.

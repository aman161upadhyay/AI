# Build one project for twelve weeks

Choose a research assistant with two tenants, authorized documents, read-only search, a durable research job, and draft artifacts. Ask: “Implement this week's bounded artifact in the existing project. Preserve previous acceptance checks and report quality, cost, and blocked work.”

Supply 30 to 50 representative tasks, known failures, an initial human rubric, a sanitized corpus, allowed licenses, and your weekly time budget. Start with read-only docs and an isolated development project. Refuse production data, live billing/email, broad cloud access, and unapproved training-data export.

Approve a per-run API/GPU ceiling and a kill switch before any experiment. Move through research, design, isolated implementation, and approved deployment access separately. Keep secret values in the host's credential manager.

Review one artifact and its failure analysis each week. Do not move to RL because the calendar says week 11 if you cannot defend the reward. Run held-out tests before selecting a change. Ask an independent reviewer to reproduce the capstone evals and recovery drill.

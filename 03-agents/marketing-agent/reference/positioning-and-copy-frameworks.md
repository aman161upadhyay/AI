# Position before choosing a headline

April Dunford's sequence starts with actual competitive alternatives. Include doing nothing or manual work. Identify capabilities that alternatives lack, map them to customer value, identify the segment that cares most, then choose a market category that makes the value understandable. A category is a communication choice to validate, not a claim of market leadership.

Use a brief with: buying situation; buyer and user; alternatives; differentiated capability; value; best-fit segment; category; proof; objections; unknowns. A capability without evidence stays a hypothesis. Do not invent interviews to complete the brief.

## Copy structures

PAS organizes problem, agitation and solution. Agitation must describe a documented consequence rather than invented fear. AIDA organizes attention, interest, desire and action. Attach proof before a high-commitment ask. Use either structure only when it helps the specific channel.

Jobs-to-be-done records situation, motivation and desired progress: "When this situation occurs, I want this progress, so I can reach this outcome." Derive the story from interviews and behavior. Label inferred stories as hypotheses.

For customer language, store the exact words with source, segment, date and permission. Count distinct people separately from repeated mentions. Preserve dissenting interviews. Never publish an inferred persona or synthetic review as research.

Review a landing page for buyer recognition, concrete job, visible mechanism, supported proof, objection handling, access requirements and one primary action. Section order is a test hypothesis. No framework guarantees conversion.

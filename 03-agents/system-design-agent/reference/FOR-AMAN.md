# Read references against one decision

Ask: “Study this subsystem in the pinned exemplar. Report its implemented pattern, evidence path, limitations, and an independent design for my constraints.”

Supply a commit, approved license scope, target subsystem, and your requirements. Grant public/read-only source access. Refuse restricted-code copying and private-data upload. Do not load whole repositories into the system prompt.

Check actual schema, auth path, tests, and deployment files before accepting a pattern. Turn it into an independent failure case with hidden tests. Compare with and without reference access and record contamination risk. Review the result before your agent proposes implementation.

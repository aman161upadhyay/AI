# Architecture artifact templates

Use these contracts after requirements are clear. Replace field descriptions with authentic project evidence; remove irrelevant fields with a reason.

- [adr.md](adr.md): decision options, dated evidence, rollback, and reconsideration.
- [data-model.md](data-model.md): ownership, constraints, query/index plan, policies, migrations.
- [api-contract.md](api-contract.md): operation and webhook semantics.
- [deployment-plan.md](deployment-plan.md): environments, release gates, recovery, and costs.
- [FOR-AMAN.md](FOR-AMAN.md): selection and review instructions.

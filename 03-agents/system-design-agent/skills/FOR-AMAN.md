# Select one procedure

Ask for architecture-review when you have a design or diff. Ask for data-model-design when ownership, schema, or migration semantics need definition. Supply the requirements and actual repository paths rather than a broad expert persona.

Grant read-only repository/docs access and an approved output directory. Refuse production migration, schema execution, and permission expansion. Run explicit activation plus near-miss tasks, then compare result quality with the no-skill baseline. Review the proposed artifact and return only evidence-backed corrections.

# Triangulation gate

- [ ] Define the exact claim before counting sources.
- [ ] Identify the underlying observation, experiment, dataset, release, or record.
- [ ] Trace each secondary report to its origin and assign a family ID.
- [ ] Separate distinct reporting from independent evidence.
- [ ] For a contested consequential claim, seek two independent families and original evidence where available.
- [ ] For a narrow official fact, explain why one authoritative record suffices.
- [ ] Inspect whether supposedly independent studies share data, authors, funding, or a benchmark setup.
- [ ] Compare definitions, versions, populations, and periods before treating results as agreement.
- [ ] Record contrary evidence and the strongest supported alternative.
- [ ] If only one family is available, attribute it and state the consequence for confidence.
- [ ] Preserve unresolved disagreements. Do not manufacture balance or consensus.

Return claim ID, origin families, independence basis, counterevidence, and disposition: corroborated, single-origin, contested, or unknown. These states describe the available evidence, not probabilities.

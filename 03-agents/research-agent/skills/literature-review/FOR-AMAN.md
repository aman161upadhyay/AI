# Use literature review

Give the agent a question, eligibility rules, date range, languages, and databases that you can access. Supply lawful full texts when the public version is incomplete. State whether you need exploratory coverage or a review for publication.

Grant scholarly search and read-only full-text access. Refuse paywall bypass and unauthorized redistribution. Require an exclusion log and review a sample of excluded papers. Run research eval `003` before trusting cross-paper comparisons. Add your own domain-specific papers and a held-out extraction key for release use.

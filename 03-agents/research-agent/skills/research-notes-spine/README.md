# Durable research notes

- `SKILL.md` defines state updates and evidence-preserving compression.
- `notes.md` specifies the human-readable spine.
- `sources-registry-schema.md` defines source and search records.
- `claim-evidence-map-schema.md` defines atomic claims and audit state.
- `FOR-AMAN.md` covers storage permissions and review.

These are schemas for a run workspace, not claims that a research run already exists.

# Preserve research state

Use for multi-step research and before every handoff or context compaction.

1. Create `notes.md`, `sources.yaml`, `claims.yaml`, and `search-log.yaml` in the authorized run workspace. Use the sibling schemas.
2. Assign stable IDs. Keep source identity separate from evidence origin. Several source IDs can share one origin family.
3. Register evidence before drafting claims. Keep exact locators into lawful snapshots or authorized originals.
4. After each work batch, update changed conclusions, coverage, contradictions, budget use, and next actions. Do not save the whole conversation as the spine.
5. Append reversals with a superseding claim ID and reason. Retain earlier wording for audit rather than silently replacing it.
6. Compress duplicate tool history and irrelevant text. Preserve uncertainty, contrary evidence, access failures, and evidence pointers.
7. Before resuming, read the brief and open gaps. Reopen originals for consequential synthesis and verification. A summary is not replacement evidence.
8. Before delivery, reconcile every report claim with the map and every cited source with the registry.

Keep private evidence in restricted storage. The public registry must omit sensitive titles, URLs, excerpts, and hashes when disclosure is prohibited. Use an internal opaque reference instead. Do not expose private document details through search queries.

Done means a new authorized researcher can identify the next question, remaining budget, and original evidence without reconstructing chat. This file design is local policy informed by Anthropic context engineering and citation-support requirements in `../../sources.md`.

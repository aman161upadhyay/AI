# Notes spine schema

Create one `notes.md` per research run with these sections. Fill them from actual work. Mark a section “not assessed” with a reason when the budget prevents assessment.

| Section | Required content |
|---|---|
| Brief and acceptance | Decision, audience, depth, output format, required questions, and definition of done. |
| Scope and permissions | Definitions, exclusions, as-of date, authorized collections, allowed destinations, and retention. |
| Plan and coverage | Question IDs with priority, evidence need, owner, state, and linked claim IDs. |
| Current conclusions | Exact working conclusion and supporting claim IDs. Distinguish proposal from finding. |
| Alternatives | Competing hypotheses, strongest counterevidence, and reversal conditions. |
| Conflicts and gaps | Conflicting claims, missing evidence, effect on the answer, and next discriminating check. |
| Access and exclusions | Source IDs not read, failed access, rejected sources, and reasons. |
| Resources | Approved caps, actual calls, retries, spend, elapsed time, remaining budget, and stop reason. |
| Handoff | Current draft revision, audit coverage, next action, and responsible owner. |

Do not place secrets or private text in a public spine. Keep a public summary separate from restricted evidence.

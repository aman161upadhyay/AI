# Research skills

Load a skill at its decision point rather than loading every reference for every request.

| Folder | Use |
|---|---|
| `source-credibility/` | Assess whether a source can support a particular claim. |
| `citation-verification/` | Audit final sentences against original evidence. |
| `question-decomposition/` | Convert the brief into bounded questions and assignments. |
| `research-notes-spine/` | Preserve evidence and unresolved gaps across work batches. |
| `literature-review/` | Run a bounded, PRISMA-inspired review with reproducible selection. |

`FOR-AMAN.md` explains selection and access. Each skill folder includes its own usage contract.

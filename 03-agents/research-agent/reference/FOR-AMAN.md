# Use the references

Load the architecture comparison when you choose a harness, not for every narrow fact request. Supply your workload and budget before asking which design fits.

Load the benchmark reference when you choose evaluation tasks. Use the human-methods reference when claims are contested. Grant read-only sources and refuse automatic installation of a linked repository. Run the full research eval suite before promoting an architectural change. Treat a failed comparison as a reason to revise the harness, not to add more agent roles by default.

# Kling and Pika adapters

[Kling's guide](https://kling.ai/quickstart/text-to-video-prompt-guide) combines subject description, movement and scene, with optional camera, lighting and atmosphere. Keep counting and complex physical trajectories out of precision-critical shots. Convert the paper-bird example into those fields rather than appending unsupported API keys.

[Pika 2.5's retrieved schema](https://dev.pika.art/llms/pika/pika-2.5/text-to-video) exposes a 5-second duration, 720p/1080p, seed and optional negative prompt as of 2026-10-25. Validate current support. An audio-upload reference does not establish native audio generation.

Keep controls outside prose. Use negatives only when a provider explicitly supports them and a concrete failure warrants them. Review each output for physical continuity and boundary quality. Do not infer another provider's features from these adapters.

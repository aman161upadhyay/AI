# Shared shot structure

```text
Purpose/output: [placement, audience, requested duration and aspect ratio]
Reference assets/rights: [approved subject, location and first frame]
Subject: [appearance and stable identifying features]
Action: [one feasible movement and necessary beats]
Camera: [framing, position, lens feel and one move]
Setting: [materials and background activity]
Lighting/palette: [source, direction, softness and colour anchors]
Style: [medium, texture, realism and operational mood]
Audio: [ambient bed, effects, exact short dialogue or no dialogue]
Continuity: [features that must remain unchanged]
Review: [identity, geometry, physical continuity, audio, rights and boundary]
```

This is an internal brief, not a provider API schema. Select model, duration, resolution, aspect and seed through supported controls. Verify the exact endpoint before generation.

Translate exclusions by provider. Veo supports exclusion descriptions in the fetched guide. Runway Gen-4 discourages negative blocks and favors positive motion. Pika's fetched schema exposes an optional negative field. Do not assume Kling or every endpoint shares those controls.

Acceptance: one coherent shot, supported settings, rights approval and inspected output. Failure modes include drifting identity, impossible motion, unstable lettering and a loop boundary that needs editing. Add exact text in post-production.

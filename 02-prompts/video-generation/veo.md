# Veo adapter

The [Google Veo 3.1 guide](https://cloud.google.com/blog/products/ai-machine-learning/ultimate-prompting-guide-for-veo-3-1), dated 2025-10-15, uses cinematography, subject, action, context and style. Explicit audio instructions can help.

Use the shared shot brief, then select supported controls separately. The retrieved guide discusses 4/6/8-second clips and reference or first/last frames. Those are snapshot observations, not current endpoint guarantees.

Ask for ambience, effects and dialogue as separate instructions. Review whether the generated audio competes with dialogue. Use approved references for continuity. Check output geometry and text rather than assuming preservation.

Start with examples 1 or 2 in `examples.md`. Accept only after settings validation, rights approval and shot inspection. No paid call is authorized by this document.

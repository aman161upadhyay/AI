# Study production prompt structure without copying leaks

- `FOR-AMAN.md`: safe reference use and original harness evaluation.

The [community collection](https://github.com/x1xhlol/system-prompts-and-models-of-ai-tools/tree/main) declares GPL-3.0. Its declaration does not establish rights in third-party prompts or authenticate their current production use. This repository copies no leaked prompt text.

[Anthropic's official system-prompt releases](https://platform.claude.com/docs/en/release-notes/system-prompts/overview) are authentic app snapshots. Publication does not establish a permissive redistribution license or a recommended default API prompt.

Research 10 observed recurring structures: environment identity, concrete tool contracts, action-versus-discussion modes, context gathering, bounded planning, safe parallelism, task-specific verification, concise completion reports and approval gates.

Implement those ideas in original language for actual tools. Document inputs, side effects, failure handling and done conditions. Do not import product-specific absolutes such as mandatory refactoring, arbitrary response limits or broad permission grants.

Known gaps: collection authenticity and currentness remain unverified. No causal evidence shows that copying a long production prompt improves a different harness.
